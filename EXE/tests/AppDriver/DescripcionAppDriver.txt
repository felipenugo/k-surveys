Objeto de la prueba:
    -Casos de uso probados:
        -Navegación por el menú principal de la aplicación
        -Responder o analizar encuestas
        -Crear encuesta
        -Cerrar sesión
        -Flujo completo de la aplicación
    -Clases probadas:
        -AppDriver
        -SurveyDriver
        -CreateSurveyDriver
        -SessionDriver
        -UserController

Ficheros de datos necesarios:
    Ninguno.
    El repositorio interno es suficiente para la ejecución de pruebas.

Valores estudiados:
    -Navegación correcta entre las opciones del menú principal.
    -Acceso a responder/analizar encuestas.
    -Acceso a crear encuestas.
    -Cerrar sesión correctamente.
    -Comportamiento con opciones inválidas.
    -Flujo completo usuario-encuesta-respuesta.

Efectos estudiados:
    Navegación correcta entre módulos.
    Mantener sesión activa durante uso.
    Cerrar sesión correctamente.
    Manejo de errores en navegación.
    Integración entre todos los drivers.

Operativa:
    El programa muestra el menú principal con las siguientes opciones:
        1. RESPONDER O ANALIZAR ENCUESTAS
        2. CREAR ENCUESTA
        3. CERRAR SESIÓN

    Para garantizar el funcionamiento:
        1. El usuario debe estar autenticado.
        2. Ejecute el AppDriver.
        3. Seleccione una opción del menú.
        4. Navegue por los diferentes módulos.
        5. Cierre sesión cuando termine.

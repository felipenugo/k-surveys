Objeto de la prueba:
    -Casos de uso probados:
        -Iniciar Sesión
        -Registrarse
        -Cerrar Sesión
        -Salir
    -Clases probadas:
        -SessionDriver
        -UserController
        -User

Ficheros de datos necesarios:
    Ninguno.

IMPORTANTE: Después de un registro exitoso, el sistema hace login automáticamente.
Los tests incluyen tanto el registro como el login subsiguiente.

Valores estudiados:
    -Registro exitoso con usuario, correo y contraseña válidos.
    -Inicio de sesión con usuario y contraseña válidos.
    -Inicio de sesión con usuario inexistente.
    -Comportamiento al escoger una opción no elegible.
    -Registro inválido con correo fuera de formato.
    -Registro inválido con campo correo vacío.
    -Inicio de sesión inválido con usuario o contraseña vacío.
    -Inicio de sesión con usuario y contraseña erróneos.
    -Registro inválido con usuario ya existente.
    -Cierre correcto de sesión.

Efectos estudiados:
    -Transiciones de estado de sesión, es decir, sesión iniciada o cerrada.
    -Manejo adecuado de errores.
    -Correcto funcionamiento en el flujo de la aplicación mediante la entrada del usuario por consola.


Operativa:
    El programa muestra los comandos disponibles por consola:
        -INICIAR SESIÓN - Iniciar sesión.
        -REGISTRARSE - Registrar usuario.
        -CERRAR SESIÓN - Cerrar sesión.
        -Intentar iniciar sesión de nuevo.
        -Volver al menú principal.
        -SALIR - Salir de la aplicación.

    Para garantizar el funcionamiento:
        1. Ejecute el ejecutable.
        2. Al principio solo podrá usar los comandos:
            -INICIAR SESIÓN [USUARIO] [CONTRASEÑA]
            -REGISTRARSE [USUARIO] [CORREO] [CONTRASEÑA]
            -SALIR 
        3. Si se hace REGISTRARSE exitoso, automáticamente hace login.
        4. Solo se podrá usar el comando:
            -CERRAR SESIÓN
        5. Repite comandos hasta que quieras salir.

NOTA: Todos los tests de SessionDriver ahora incluyen el flujo completo de registro+login automático.

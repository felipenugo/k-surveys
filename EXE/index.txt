EXE - Directorio de ejecutables

Este directorio contiene:
- Makefile: Archivo para EJECUTAR la aplicación (no compila)
- classes/: Clases compiladas (.class) generadas por Gradle
- FormsApp.jar: JAR ejecutable generado por Gradle
- tmp_*.txt: Archivos temporales de entrada/salida para pruebas

IMPORTANTE: Este Makefile solo ejecuta la aplicación.
Para compilar, utilice Gradle en el directorio FONT/.

Para compilar el proyecto (primer paso):
cd ../FONT && ./gradlew jar

Para ejecutar con el Makefile:
1. make run     - Ejecuta la CLI
3. make clean   - Limpia archivos temporales

Para ejecutar con archivos de entrada/salida:
make run INPUT=../DATA/input.txt OUTPUT=../DATA/output.txt

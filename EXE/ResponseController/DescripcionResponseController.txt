Objeto de la prueba:
    -Casos de uso probados:
        -Editar Respuestas
		-Enviar Respuestas
	((((((((Seleccionar encuesta para responder Mostrar preguntas Responder pregunta Ver respuestas Enviar respuesta Volver atras )))))))))
    	-Clases probadas:
        	-ResponseController
			-SurveyController (solo lectura de encuestas)
			-EditResponseDriver
			-ResponseDriver
			-Modelos: Question, Answer, TextualAnswer, MultipleChoiceAnswer, NumericalAnswer

Ficheros de datos necesarios:
    Ninguno.
    El repositorio interno (SurveyRepository, ResponseRepository, UserRepository) es suficiente para la ejecucion de pruebas.

Valores estudiados:
    -EL sistema lista las encuestas creadas de manera correcta para poder escoger una y responderla
    -Seleccionar encuesta valida
    -Seleccionar encuesta inexistente
    -Comportamiento al escoger una opcion no elegible
    -Muestra todas las preguntas de la encuesta correctamente
    -Funcionamiento correcto de respuesta a todo tipo de preguntas + correcto funcionamiento de enviar respuesta
    -Funcionamiento incorrecto de respuesta a todo tipo de preguntas
    -Correcto funcionamiento de VER MIS RESPUESTAS, en caso de no haber respuestas lo dice. En caso contrario las lista.
    

Efectos estudiados:
   ✔ Transiciones del estado de la respuesta
	- Inicio de respuesta
	- Responder preguntas
	- Guardar respuestas
	- Enviar respuesta (finalizar)

✔ Manejo correcto de errores y excepciones:
	- SurveyException
	- ResponseException
	- InputMismatchException

✔ Flujo completo de la aplicacion mediante entrada por consola, verificando que:
	- Los menus funcionan correctamente
	- Los bucles de interaccion no se rompen
	- Se permiten reintentos cuando procede
	- Se vuelve a los menus superiores cuando corresponde

Operativa:
   El programa muestra los comandos disponibles para gestionar respuestas:
	Desde ResponseDriver:
	   1. Seleccionar encuesta para responder
	   2. Volver atras

	Desde EditResponseDriver:
	   1. Ver preguntas
	   2. Responder pregunta
	   3. Ver mis respuestas
	   4. Enviar respuesta

   Para garantizar el funcionamiento:
	Ejecutar la aplicacion con un usuario ya logueado (ya que responder encuestas requiere sesion iniciada).

	Seleccionar la opcion:
	RESPONDER ENCUESTAS
	Y luego Seleccionar encuesta para responder.

	El sistema muestra todas las encuestas disponibles.
	Se deben validar estos comportamientos:

	Encuesta valida → inicia respuesta
	Encuesta inexistente → error + menu de reintento

	Una vez iniciada la respuesta, utilizar el menu del editor:

	1. Ver preguntas debe mostrar todo correctamente

	2. Responder pregunta debe admitir:
		- Texto valido
		- Numeros validos
		- Opciones multiples validas
	Cualquier respuesta incorrecta debe producir el mensaje adecuado y mostrar menu de error

	3. Ver respuestas debe:
		- Mostrar “no respondida” si procede
		- Mostrar respuestas guardadas

	4. Al seleccionar ENVIAR RESPUESTA, el sistema pedira confirmacion:
		- Si el usuario confirma → se envia
		- Si no confirma → vuelve al menu

   El driver retorna al menu superior tras finalizar el proceso.

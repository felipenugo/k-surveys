DESCRIPCIÓN GENERAL
-------------------
El DriverClustering es una interfaz de línea de comandos (CLI) diseñada para 
probar y comparar los tres algoritmos de clustering implementados: KMeans, 
KMeansPlusPlus y KMedoids.

Permite:
  • Generar datasets sintéticos con clusters bien definidos
  • Cargar datos manualmente desde la entrada estándar
  • Ejecutar algoritmos de clustering individuales
  • Comparar los 3 algoritmos sobre el mismo dataset
  • Visualizar resultados, distribuciones y métricas
  • Gestionar múltiples análisis simultáneamente

  ┌──────────────────────────┐

  ┌──────────▼────────────────┐

  │ • KMeans                   │

EJECUCIÓN
---------
Compilar y ejecutar con Gradle:
  
  ./gradlew build
  ./gradlew run --args="drivers.DriverClustering"

O ejecutar directamente la clase compilada:
  
  java -cp build/classes/java/main drivers.DriverClustering

DESCRIPCIÓN DE COMANDOS
------------------------

1. CREAR - Generar Datos Sintéticos
   Crea un dataset con clusters gaussianos bien separados.
   
   Entradas:
     • Nombre del dataset: identificador único
     • Puntos por cluster: número de puntos en cada cluster
     • Número de clusters: cuántos clusters generar
     • Dimensiones: número de características por punto
   
   Ejemplo:
     Nombre del dataset: test_3clusters
     Número de puntos por cluster: 50
     Número de clusters: 3
     Número de dimensiones: 2


2. CARGAR - Cargar Datos Manualmente
   Permite introducir datos punto por punto desde teclado.
   
   Entradas:
     • Nombre del dataset
     • Número de puntos total
     • Dimensiones
     • Valores de cada punto (separados por espacios)
   
   Ejemplo:
     Punto 0: 1.5 2.3
     Punto 1: 1.8 2.1
     Punto 2: 8.5 9.2


3. EJECUTAR - Ejecutar Algoritmo Individual
   Ejecuta un algoritmo sobre un dataset existente.
   
   Entradas:
     • Dataset a usar
     • Algoritmo (1=KMeans, 2=KMeansPlusPlus, 3=KMedoids)
     • Número de clusters (k)
     • Opcionales: maxIterations, tolerance
   
   Salida:
     • Tiempo de ejecución
     • ID del análisis generado
     • Número de iteraciones
     • Convergencia alcanzada
     • Distribución de puntos por cluster


4. COMPARAR - Comparar Algoritmos
   Ejecuta los 3 algoritmos sobre el mismo dataset y compara resultados.
   
   Entradas:
     • Dataset a usar
     • Número de clusters (k)
   
   Salida:
     • Tabla comparativa con tiempo, iteraciones, convergencia
     • Distribución de puntos para cada algoritmo


5. VER - Ver Resultados
   Muestra el resumen completo de un análisis guardado.
   
   Entradas:
     • ID del análisis
   
   Salida:
     • Nombre del algoritmo
     • Número de puntos y clusters
     • Iteraciones y convergencia
     • Distribución de puntos


6. INFO - Información de Cluster
   Muestra detalles de un cluster específico.
   
   Entradas:
     • ID del análisis
     • ID del cluster (0 a k-1)
   
   Salida:
     • Puntos en el cluster
     • Centroide del cluster
     • Distancia promedio al centroide


7. LISTAR - Listar Análisis
   Muestra todos los análisis guardados en memoria.


8. LIMPIAR - Limpiar Análisis
   Elimina todos los análisis de la memoria.

NOTAS TÉCNICAS
==============

Formato de Datos
----------------
• Los datos se representan como Object[][] (matriz de objetos)
• Cada fila es un punto, cada columna es una dimensión
• Los valores deben ser numéricos (Double)

Algoritmos
----------
• KMeans: Inicialización aleatoria, puede caer en mínimos locales
• KMeansPlusPlus: Inicialización inteligente (D²), mejor resultado inicial
• KMedoids: Usa puntos reales como centroides, más robusto a outliers

Métricas
--------
• Distancia: Euclidiana (sqrt(sum((x_i - y_i)²)))
• Convergencia: Cambio en centroides < tolerance O iteraciones >= maxIterations

Rendimiento
-----------
• KMeansPlusPlus suele converger más rápido que KMeans
• KMedoids es más lento (O(n²) vs O(n)) pero más robusto
• Tiempo típico para 100 puntos, 3 clusters, 2D: 20-100ms


ERRORES COMUNES
===============

1. "Dataset no encontrado"
   → Verifica que hayas creado o cargado el dataset antes de usarlo
   → Usa LISTAR para ver datasets disponibles

2. "Número de clusters inválido"
   → k debe ser > 0 y <= número de puntos
   → Para n puntos, k típicamente entre 2 y sqrt(n)

3. "No hay análisis guardados"
   → Primero ejecuta un algoritmo con EJECUTAR o COMPARAR
   → Los análisis se pierden al cerrar el programa

4. "Algoritmo no convergió"
   → Aumenta maxIterations (default 100)
   → Puede ser normal con k muy grande o datos sin estructura

DESCRIPCION GENERAL
-------------------
El DriverClustering es una interfaz de línea de comandos (CLI) diseñada para 
probar y comparar los tres algoritmos de clustering implementados: KMeans, 
KMeansPlusPlus y KMedoids.

Permite:
  • Generar datasets sinteticos con clusters bien definidos
  • Cargar datos manualmente desde la entrada estandar
  • Ejecutar algoritmos de clustering individuales
  • Comparar los 3 algoritmos sobre el mismo dataset
  • Visualizar resultados, distribuciones y metricas
  • Gestionar multiples analisis simultaneamente

------------

  ┌──────────────────────────┐

  └──────────┬────────────────┘
             │
  ┌──────────▼────────────────┐
  │   Algoritmos de Clustering│  ← CAPA DE DOMINIO

  │ • KMeansPlusPlus           │

  └────────────────────────────┘


EJECUCION
---------
Compilar y ejecutar con Gradle:
  
  ./gradlew build
  ./gradlew run --args="drivers.DriverClustering"

O ejecutar directamente la clase compilada:
  
  java -cp build/classes/java/main drivers.DriverClustering

DESCRIPCION DE COMANDOS
------------------------

1. CREAR - Generar Datos Sinteticos
   Crea un dataset con clusters gaussianos bien separados.
   
   Entradas:
     • Nombre del dataset: identificador unico
     • Puntos por cluster: numero de puntos en cada cluster
     • Numero de clusters: cuantos clusters generar
     • Dimensiones: numero de caracteristicas por punto
   
   Ejemplo:
     Nombre del dataset: test_3clusters
     Numero de puntos por cluster: 50
     Numero de clusters: 3
     Numero de dimensiones: 2


2. CARGAR - Cargar Datos Manualmente
   Permite introducir datos punto por punto desde teclado.
   
   Entradas:
     • Nombre del dataset
     • Numero de puntos total
     • Dimensiones
     • Valores de cada punto (separados por espacios)
   
   Ejemplo:
     Punto 0: 1.5 2.3
     Punto 1: 1.8 2.1
     Punto 2: 8.5 9.2


3. EJECUTAR - Ejecutar Algoritmo Individual
   Ejecuta un algoritmo sobre un dataset existente.
   
   Entradas:
     • Dataset a usar
     • Algoritmo (1=KMeans, 2=KMeansPlusPlus, 3=KMedoids)
     • Numero de clusters (k)
     • Opcionales: maxIterations, tolerance
   
   Salida:
     • Tiempo de ejecucion
     • ID del analisis generado
     • Numero de iteraciones
     • Convergencia alcanzada
     • Distribucion de puntos por cluster


4. COMPARAR - Comparar Algoritmos
   Ejecuta los 3 algoritmos sobre el mismo dataset y compara resultados.
   
   Entradas:
     • Dataset a usar
     • Numero de clusters (k)
   
   Salida:
     • Tabla comparativa con tiempo, iteraciones, convergencia
     • Distribucion de puntos para cada algoritmo


5. VER - Ver Resultados
   Muestra el resumen completo de un analisis guardado.
   
   Entradas:
     • ID del analisis
   
   Salida:
     • Nombre del algoritmo
     • Numero de puntos y clusters
     • Iteraciones y convergencia
     • Distribucion de puntos


6. INFO - Informacion de Cluster
   Muestra detalles de un cluster especifico.
   
   Entradas:
     • ID del analisis
     • ID del cluster (0 a k-1)
   
   Salida:
     • Puntos en el cluster
     • Centroide del cluster
     • Distancia promedio al centroide


7. LISTAR - Listar Analisis
   Muestra todos los analisis guardados en memoria.


8. LIMPIAR - Limpiar Analisis
   Elimina todos los analisis de la memoria.

NOTAS TECNICAS
==============

Formato de Datos
----------------
• Los datos se representan como Object[][] (matriz de objetos)
• Cada fila es un punto, cada columna es una dimension
• Los valores deben ser numericos (Double)

Algoritmos
----------
• KMeans: Inicializacion aleatoria, puede caer en mínimos locales
• KMeansPlusPlus: Inicializacion inteligente (D²), mejor resultado inicial
• KMedoids: Usa puntos reales como centroides, mas robusto a outliers

Métricas
--------
• Distancia: Euclidiana (sqrt(sum((x_i - y_i)²)))
• Convergencia: Cambio en centroides < tolerance O iteraciones >= maxIterations

Rendimiento
-----------
• KMeansPlusPlus suele converger mas rápido que KMeans
• KMedoids es mas lento (O(n²) vs O(n)) pero mas robusto
• Tiempo tipico para 100 puntos, 3 clusters, 2D: 20-100ms


ERRORES COMUNES
===============

1. "Dataset no encontrado"
   → Verifica que hayas creado o cargado el dataset antes de usarlo
   → Usa LISTAR para ver datasets disponibles

2. "Numero de clusters inválido"
   → k debe ser > 0 y <= numero de puntos
   → Para n puntos, k tipicamente entre 2 y sqrt(n)

3. "No hay analisis guardados"
   → Primero ejecuta un algoritmo con EJECUTAR o COMPARAR
   → Los analisis se pierden al cerrar el programa

4. "Algoritmo no convergi0"
   → Aumenta maxIterations (default 100)
   → Puede ser normal con k muy grande o datos sin estructura

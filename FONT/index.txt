El directorio FONT contiene el código fuente y ejemplos de la aplicación.

build.gradle            Configuración de Gradle, incluye tarea javadoc para generar documentación con diagramas UML
settings.gradle         Configuración de settings de Gradle
gradlew                 Script Gradle Wrapper para Linux/Mac
gradlew.bat             Script Gradle Wrapper para Windows
data/                   Capa de persistencia en memoria (repositorios)
domain/                 Lógica de negocio (modelos, servicios, controladores, clustering)
presentation/           Capa de presentación (drivers y main)
test/                   Tests unitarios y de integración
build/                  Archivos compilados generados por Gradle
bin/                    Archivos binarios compilados
gradle/                 Configuración del wrapper de Gradle

IMPORTANTE: Este directorio contiene el código fuente.
Para compilar y ejecutar, consulte el Makefile en el directorio EXE/.

Para generar JavaDoc con diagramas UML (requiere Graphviz instalado):
./gradlew javadoc

Para compilar el proyecto:
./gradlew jar

Para ejecutar tests:
./gradlew test

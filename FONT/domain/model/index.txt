Objetos del modelo de dominio que representan entidades principales del sistema (Survey, Question, Response, etc.).

Archivos:
- User.java: Entidad User que almacena credenciales y metadatos.
- Survey.java: Representa una encuesta con metadatos y preguntas.
- Question.java: Clase base para preguntas; sus subtipos concretos siguen.
- MultipleChoiceQuestion.java, OptionQuestion.java, etc.: Subtipos de pregunta.
- Answer.java: Clase base para respuestas; subtipos concretos incluyen MultipleChoice, Numerical, Textual.
- Response.java: Representa las respuestas de un usuario a una encuesta.

Subcarpetas:
- enums: Contiene enumeraciones del dominio como TypeQuestion, SurveyStatus, ResponseStatus.

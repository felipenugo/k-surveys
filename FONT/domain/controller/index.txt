Controladores de dominio: proporcionan métodos de fachada que usan servicios y repositorios para implementar casos de uso.

Archivos:
- AnalysisController.java: Controlador de alto nivel que orquesta análisis de clustering.
- AnswerController.java: Controlador para gestionar respuestas y su validación.
- CtrlDominioClustering.java: Controlador de dominio para flujos relacionados con clustering.
- QuestionController.java: Controlador para gestionar preguntas y operaciones relacionadas.
- ResponseController.java: Controlador para gestionar respuestas y validarlas.
- SurveyController.java: Controlador para gestionar encuestas, su creación y ciclo de vida.
- UserController.java: Controlador para registro de usuarios, login y operaciones de perfil.
